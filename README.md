# Pharmacy Inventory Analysis & Dashboard

## Project Overview

This project analyzes a sample pharmacy inventory dataset using Microsoft Excel.

## Objectives

* Track medicine stock levels.
* Calculate total inventory value.
* Identify low-stock medicines.
* Monitor medicine expiry status.
* Analyze inventory by category and supplier.

## Tools and Skills

* Microsoft Excel
* IF, COUNTIF, SUMIF, SUM, AVERAGE, MAX and MIN
* VLOOKUP
* Data Cleaning
* Conditional Formatting
* Pivot Tables
* Charts and Dashboard Design

## Key Features

* Inventory value calculation
* Low-stock identification
* Expiry status classification
* Category-wise stock analysis
* Supplier-wise inventory analysis
* Summary dashboard with KPIs and charts

## Dataset

A sample dataset containing 20 medicines, their categories, stock quantities, prices, expiry dates and suppliers.

## Disclaimer

This is an educational portfolio project using sample data. It is not a live pharmacy management system.
